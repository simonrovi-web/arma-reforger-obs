Editor de textos

Cambia los textos y pulsa Aplicar: las gráficas abiertas se actualizan solas. Vacío = el texto de config.js.
¿Has abierto el editor en Chrome u otro navegador? Entonces «Aplicar» no llega a OBS (cada programa guarda sus textos aparte). Dos formas de que sí llegue:
1) Añade este editor dentro de OBS: Docks → Docks de navegador personalizados → pega esta misma dirección.
2) Escribe tus textos y pulsa Copiar URL para OBS en la sección: pega esa URL en la fuente de navegador de OBS.
